# VK007 — VK Activity Monitor & Dialogue Detector

Telegram-бот на базе `aiogram 3.x` и `vk-api` для мониторинга активности и корреляционного анализа присутствия пользователей в социальной сети ВКонтакте.

## 🕵️‍♂️ Как это работает

1. **Периодический мониторинг**:
   - Пользователь задает один или несколько целевых VK ID и выбирает тайм-аут мониторинга (от 10 минут до 24 часов).
   - Каждые 5 минут бот запрашивает через VK API статус цели и список всех её друзей (`online`, `last_seen`).

2. **Корреляционный анализ (выявление диалогов)**:
   - Алгоритм сопоставляет временные метки присутствия цели и каждого её друга:
     - **Онлайн-совпадение**: цель и друг одновременно находятся в сети.
     - **Оффлайн-совпадение**: цель и друг выходят из сети синхронно (разница `last_seen` менее 300 секунд).
   - Если коэффициент корреляции превышает заданный порог (80%), алгоритм отмечает пару как **подозрительную** (высокая вероятность активной переписки / скрытого общения между ними).

3. **Расчет сессий**:
   - Вычисляет непрерывные интервалы нахождения цели в сети с точным временем начала, окончания и продолжительностью в минутах.

4. **Генерация отчета**:
   - По окончании формируется интерактивный HTML-отчет в темной теме (на Tailwind CSS) с таблицами совпадений, сессий, статистикой задержек визитов и подробным журналом проверок.
   - Файл отчета автоматически отправляется пользователю в Telegram-чат.

## 📋 Требования и стек

- **Python 3.10+**
- `aiogram` (v3) — асинхронный Telegram-фреймворк.
- `vk-api` — работа с методами VK API (`users.get`, `friends.get`).
- `python-dotenv` — конфигурация через переменные окружения.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/coneex243/VK007.git
cd VK007
```

### 2. Установка зависимостей
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Настройка конфигурации
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
- `BOT_TOKEN`: токен вашего бота от `@BotFather`.
- `VK_TOKEN`: сервисный ключ доступа приложения VK или токен пользователя.

### 4. Запуск бота
```bash
python vk007.py
```
